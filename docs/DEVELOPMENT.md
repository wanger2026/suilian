# USB 与远程真机联调

只连接 VPN 不会启用调试。使用者必须拥有手机与电脑，并在手机的已配对远控会话中主动授权本次 AI 联调。

首次准备：

1. 手机开启开发者选项、USB 调试；USB 接电脑后在手机上核对并允许电脑的调试指纹。
2. Android 11+ 开启“无线调试”，允许当前 Wi-Fi；某些系统还需要开启“USB 安装”并确认安装弹窗。
3. 电脑管理器“设备工具 → USB 无线配对”执行检查与配对。程序会提示尚未开启的系统权限；系统安全确认由用户完成。
4. 手机进入随连远控画面，打开 AI 联调并授权本次会话。端口可自动发现，但权限弹窗、设备锁屏和厂商限制不能绕过。
5. 在完整 Windows 包中调用 `adb-phone.cmd devices` 或其他明确需要的 ADB 命令。桥接的专用 ADB 服务与日常 USB ADB 分开。

退出远控或关闭本次授权后，桥接应停止。不要将本机 ADB 或管理接口暴露到公网。无线调试是否能在移动网络或熄屏后持续工作，取决于 Android 和厂商系统；虚拟组网并不等同于同一物理 Wi-Fi，不能保证解锁所有系统限制。
