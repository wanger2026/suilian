# 架构、数据与外部连接

Android 的 VpnService 提供 TUN 接口，FlClash/Mihomo 负责 DNS、规则与连接分流。需要电脑的连接通过 EasyTier 的加密直连到 Windows Go 代理，再交给 Windows 当前网络出口。手机不读取路由器订阅，也不需要路由器管理密码。电脑出口如何处理请求由用户自己的网络配置决定。

RustDesk、Moonlight 与 AI 调试共用已配对的私有网络，但会话生命周期各自控制。常驻 VPN 不自动打开远控，也不自动授予 ADB 权限。

## 应用绕过与规则直连

1. **完全绕过应用**：Android VpnService 排除名单中的应用使用手机原网络，不进入随连内核、不采集流量。
2. **DIRECT 规则**：其他应用仍进入 TUN，经域名规则判定后直接从手机当前物理网络发出。
3. **COMPUTER 规则**：通过已配对的电脑出口发出，可能被电脑的现有上游网络再次分流。

现阶段不能让系统仅在单个请求走电脑时显示 VPN。某些应用会检查 Android 全局 VPN 状态，加入绕过名单也不保证消除这种检查。

## 地址与服务

| 地址 / 入口 | 用途 |
|---|---|
| `10.144.77.0/24` | 程序约定的虚拟组网地址，非某位使用者的真实内网 |
| `172.19.0.2`、`198.18.0.0/16` | Android TUN / Fake-IP 技术地址 |
| `127.0.0.1` 管理端口 | 本机管理与开发桥接口，不应映射到公网 |
| `tcp://225284.xyz:11010`、`wss://et.vv1234.cn` | 默认社区发现入口，可配置；双方禁用业务中继回退 |
| `stun.miwifi.com:3478`、`stun.chat.bilibili.com:3478` | STUN 辅助确定 NAT 映射 |
| 公共 DNS | 用于解析和规则判断，源码中可查到具体解析器 |

这些服务由第三方维护。它们可能观察连接的公网源地址和时间；“禁止业务中继”不等于“不联系任何第三方”。服务可用性和隐私政策不由本项目控制。可自行配置发现入口，变更后重新配对并验证直连。

## 状态保存与历史

- Windows 配对等敏感状态使用当前用户的加密存储；流量历史存放在 `%LOCALAPPDATA%/WangChuanLink/`。本机用户账户和文件权限仍应受到保护。
- Android 状态保存在应用私有目录，包括 `traffic-history.db`；不写入公共下载目录。
- 手机历史按活动连接采样，约每 30 秒尝试通过已配对通道同步；离线时保留待同步数据，恢复可达后继续。修订号避免同一汇总被重复累计。
- 手机应用统计与电脑实际 TCP 出口统计是两个口径，不能相加作为总用量。完全绕过 VPN 的应用以及部分短连接可能不计入。
- 历史最长保留 365 天；内容是日期、软件名/包名、域名/IP、线路、协议与字节数，不包含网页路径或内容。它仍属于隐私数据，不能上传公开 issue。
