| 源码完整性 | Mihomo 与 RustDesk 补丁能应用到固定上游；已从公开副本重新编译改动后的网络核心和 Flutter 界面 |

密钥检查使用 Gitleaks。配置仅精确允许两个技术哈希清单中 `auth-*.svg` 图标的 SHA-256 字段，不排除测试目录或普通凭据字段。源码树检查与 GitHub Actions 用于降低后续误提交风险，不能保证发现所有形式的敏感信息。

本次公开流程不更新用户的在用客户端，不上传既有安装包，也不重新连接用户手机。公开版使用通用规则；它不是个人路由器配置的导出，也不是对任意网络、厂商系统、长时间耗电或固定帧率的保证。
