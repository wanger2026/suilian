# 当前限制

- 测试版，主要目标是 Windows x64 + Android arm64，一台电脑配一部手机；不是托管 VPN 服务。
- 严格 P2P：对称 NAT、运营商限制、UDP 被阻断等情形可能无法直连，不自动改走业务中继。
- 切换 Wi-Fi / 移动网络可能需要几十秒重新建立映射；“已连接”或 VPN 图标不代表所有业务均可访问。
- 域名规则不可能覆盖所有 App；浏览器电脑版标识、服务自身限制、DNS 缓存也可能影响某些站点。普通规则直连与应用完全绕过不同。
- IPv6 出口支持有限，当前配置对未处理 IPv6 请求采取拒绝；IPv6-only 等网络需要单独验证。
- 某些应用拒绝检测到 VPN 的设备环境，完全绕过 VPN 也不一定隐藏系统状态。
- 历史是采样与代理出口统计，可能漏计短连接，完全绕过应用不统计；不是完整网络审计或精确计费。
- 高帧率依赖 Sunshine 编码器、电脑 GPU、手机解码器和链路质量，不能承诺固定 120 FPS。
- AI 真机联调需要 Android 系统授权，不能替用户开启开发者选项、解锁或绕过安装确认；网络变化可能使无线调试停止。
- 长期耗电、所有厂商后台保活和任意网络的连续稳定性并未完成全面验证。没有公开正式签名或自动更新通道。
- 开源导出版本使用通用规则与可配置构建路径；公开后的二进制应独立完成设备验收，不把个人环境的测试当成普遍保证。
